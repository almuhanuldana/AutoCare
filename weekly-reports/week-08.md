# 8-апталық есеп — Жоспарлау және репозиторий құру

**Жоба тақырыбы:** Автосервис қызметтерін басқару жүйесі  
**Жобаның атауы:** AutoCare

## 1. Жобаның мақсаты
Автосервис қызметтерін көрсету процесін цифрландыруға арналған веб-қосымшаның жобасын әзірлеу. Клиент қызметтерді қарап, көлігі туралы мәлімет енгізіп, техникалық қызмет көрсетуге жазыла алады. Әкімші қызметтер мен жазылуларды басқара алады.

## 2. Негізгі функциялар
- Пайдаланушыны тіркеу және жүйеге кіргізу.
- Клиенттің көлігі туралы мәліметтерді сақтау.
- Қызметтер каталогын көрсету.
- Қызметтерді іздеу және санаты бойынша сүзгілеу.
- Қызметке күн мен уақыт таңдап жазылу.
- Жазылу мәртебесін көрсету.
- Жазылуды қосу, көру, өңдеу және жою.
- Әкімшіге қызметтерді басқару мүмкіндігін беру.
- Жөндеу тарихын сақтау.

## 3. Жоспарланған беттер
1. `index.html` — басты бет.
2. `services.html` — қызметтер каталогы.
3. `booking.html` — қызметке жазылу формасы.
4. `login.html` — жүйеге кіру.
5. `register.html` — тіркелу.

## 4. Дерекқордың бастапқы құрылымы
- `users` — пайдаланушылар және рөлдер.
- `vehicles` — клиенттердің көліктері.
- `services` — автосервис қызметтері.
- `appointments` — қызметке жазылулар.
- `service_history` — орындалған қызметтердің тарихы.

ER-диаграмма `docs/ER-diagram.svg` файлында. SQL бастапқы схема `database/schema.sql` файлында.

## 5. Технологиялар
HTML, CSS, JavaScript — интерфейс үшін; PHP — серверлік логика үшін; MySQL — деректерді сақтау үшін; GitHub — жобаның нұсқаларын сақтау үшін; XAMPP — жергілікті сервер ортасы ретінде.

## 6. 8-апта нәтижесі
Жобаның тақырыбы, мақсаты, негізгі функциялары, беттер тізімі және дерекқордың бастапқы моделі анықталды. README және ER-диаграмма дайындалды.

## 7. Келесі аптаға жоспар
HTML, CSS және JavaScript көмегімен кемінде үш адаптивті статикалық бетті әзірлеу және олардың навигациясын байланыстыру.

**Есептегі прогресс:** жоспарлау кезеңі аяқталды. Нақты пайызды өз жұмысыңның орындалуына қарай көрсет.
