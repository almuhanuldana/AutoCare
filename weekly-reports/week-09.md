# 9-апталық есеп — Пайдаланушы интерфейсін әзірлеу

**Жоба тақырыбы:** Автосервис қызметтерін басқару жүйесі  
**Жобаның атауы:** AutoCare

## 1. Аптаның мақсаты
HTML, CSS және JavaScript көмегімен веб-қосымшаның негізгі беттерінің адаптивті интерфейсін әзірлеу.

## 2. Орындалған жұмыстар
- Басты беттің құрылымы жасалды.
- Автосервис қызметтерінің каталогы жасалды.
- Қызметке жазылу формасы жасалды.
- Тіркелу және жүйеге кіру беттері әзірленді.
- Барлық беттерге ортақ навигация және footer қосылды.
- CSS арқылы жұмыс үстелі мен мобильді экрандарға бейімделетін дизайн жасалды.
- JavaScript арқылы қызметтерді іздеу және санат бойынша сүзгілеу орындалды.
- Жазылу формасына міндетті өрістер мен браузерлік валидация қосылды.
- Каталогтан жазылу бетіне өткенде таңдалған қызметті алдын ала толтыру қосылды.

## 3. Қазіргі шектеулер
Бұл кезеңде интерфейс статикалық. Формалар серверге мәлімет жібермейді және MySQL дерекқорына сақтамайды. Тіркелу, кіру және нақты жазылу функциялары PHP және MySQL қосылатын келесі кезеңдерде орындалады.

## 4. Келесі аптаға жоспар
HTML беттерін PHP файлдарына көшіру, ортақ header/footer бөліктерін бөлу, формаларды `$_POST` және `$_GET` арқылы өңдеуге дайындық жасау.

**Есептегі прогресс:** интерфейстің дайындалған беттерін тексергеннен кейін нақты пайызын көрсет.
