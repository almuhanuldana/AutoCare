
# 10-апталық есеп — PHP негіздері және серверлік құрылым

**Жоба атауы:** AutoCare  
**Жоба тақырыбы:** Автосервис қызметтерін басқару жүйесі.

## 1. Аптаның мақсаты

HTML интерфейстерін PHP форматына көшіру, серверлік құрылымды ұйымдастыру және HTML формаларын PHP арқылы өңдеу.

## 2. Орындалған жұмыстар

1. Негізгі HTML беттері PHP файлдарына көшірілді.
2. Басты бет `index.php` форматына ауыстырылды.
3. Қызметтер беті `services.php` форматына ауыстырылды.
4. Жазылу беті `booking.php` форматына ауыстырылды.
5. Тіркелу және кіру беттері PHP форматына көшірілді.
6. Қайталанатын Header және Footer бөліктері жеке файлдарға бөлінді.
7. `include` және `require_once` командалары қолданылды.
8. Жоба қалталары ұйымдастырылды: `config`, `includes`, `css`, `js`, `database`, `docs`.
9. Формаларды өңдеу кезінде `$_POST` және `$_GET` қолданылды.
10. Сервер жағында міндетті өрістерді, email, телефон және басқа мәліметтерді тексеру қарастырылды.
11. PHP файлдарының синтаксисі тексерілді.

## 3. Қазіргі жобаның жағдайы

- PHP беттері: дайын.
- Ортақ Header және Footer: дайын.
- Жоба қалтасының құрылымы: дайын.
- GET және POST әдістері: қолданылған.
- Серверлік валидация: енгізілген.

**Орындалу деңгейі:** 100% (10-аптаның тапсырмалары толық тексерілгеннен кейін).

## 4. Кездескен мәселелер және шешімдері

**Мәселе:** Header және Footer бөліктерінде HTML құрылымының қайталануы байқалды.

**Шешімі:** Ортақ файлдардағы артық main тегтері алынып, беттердің HTML құрылымы реттелді.

**Мәселе:** README файлында жобаның статикалық және PHP нұсқалары туралы ақпарат сәйкес келмеді.

**Шешімі:** README жаңартылып, қазіргі жобаның құрылымы мен орындалған жұмыстар сипатталды.

## 5. Келесі аптаға жоспар

- MySQL дерекқорын құру және тексеру.
- PDO арқылы дерекқорға қосылу.
- Пайдаланушыны тіркеу және жүйеге кіруді толық тексеру.
- Session және logout функцияларын тексеру.
