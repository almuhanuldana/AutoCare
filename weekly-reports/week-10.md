# 10-апта есебі — PHP және MySQL интеграциясы

## Аптаның мақсаты

9-аптада жасалған статикалық веб-беттерді PHP тіліне көшіру, дерекқормен байланыстыру және пайдаланушы енгізген мәліметтерді сервер жағында өңдеу.

## Орындалған жұмыстар

1. HTML беттері PHP форматына көшірілді.
2. Ортақ `header.php` және `footer.php` файлдары `includes/` қалтасына бөлінді.
3. MySQL дерекқорына PDO арқылы қосылу бапталды.
4. `services.php` бетінде қызметтер дерекқордан шығарылды.
5. `$_GET` арқылы қызметтерді іздеу және санат бойынша сүзу іске асырылды.
6. `booking.php` бетінде онлайн жазылу формасы жасалды.
7. `$_POST` арқылы форма мәліметтері қабылданып, сервер жағында тексерілді.
8. Өтінімдер `appointments` және `vehicles` кестелеріне сақталды.
9. PHP файлдарының синтаксисі тексерілді.
10. Дерекқорға қосылу және қызметтер бетін браузерде ашу тексерілді.

## Қолданылған технологиялар

- PHP 8.2
- MySQL
- PDO
- HTML5
- CSS3
- JavaScript
- XAMPP

## Тексеру нәтижелері

- PHP файлдарында синтаксистік қателер анықталған жоқ.
- MySQL дерекқорына қосылу сәтті орындалды.
- Дерекқордағы 5 кесте анықталды: `appointments`, `service_history`, `services`, `users`, `vehicles`.
- `services.php` беті сәтті ашылды.
- Жазылу формасы тексерілді.

## Қорытынды

10-аптада AutoCare жобасының PHP және MySQL интеграциясы орындалды. Қызметтерді дерекқордан көрсету және жазылу формасының мәліметтерін серверде өңдеу жүзеге асырылды.

**Апта нәтижесі:** негізгі тапсырмалар орындалды.
