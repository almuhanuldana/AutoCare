# AutoCare — Автосервис қызметтерін басқару жүйесі

## Жоба туралы
**Тақырып:** Автосервис қызметтерін басқару жүйесі  
**Технологиялар:** HTML, CSS, JavaScript (9-аптадағы интерфейс); келесі кезеңдерде PHP және MySQL қосылады.  
**Мақсаты:** Клиенттерге автосервис қызметтерін қарауға және көлікке техникалық қызмет көрсетуге жазылуға мүмкіндік беретін веб-қосымшаның прототипін жасау.

## Қазіргі кезеңнің шекарасы
Бұл репозиторий 8 және 9-апта тапсырмаларына арналған:
- 8-апта: тақырып, мақсат, функциялар тізімі, дерекқордың бастапқы құрылымы, ER-диаграмма, GitHub README.
- 9-апта: кемінде 3 статикалық беттен тұратын адаптивті интерфейс.

**Маңызды:** осы кезеңде тіркелу, кіру және жазылу формалары интерфейс ретінде көрсетілген. Мәліметтер MySQL-ге әлі сақталмайды. PHP + MySQL серверлік бөлігі кейінгі апталарда жасалады.

## Негізгі функциялар
1. Қызметтер каталогын қарау.
2. Қызметтерді атауы немесе санаты бойынша іздеу/сүзу (қазір браузер ішінде демо).
3. Көлік туралы мәлімет енгізу.
4. Қызмет көрсетуге жазылу формасын толтыру.
5. Тіркелу және жүйеге кіру беттерінің интерфейсі.
6. Қызметтер, көліктер, жазылулар және пайдаланушыларға арналған дерекқор құрылымы.
7. Келесі кезеңде клиент/әкімші рөлдерін және жазылу мәртебесін енгізу.

## Беттер
- `index.html` — басты бет.
- `services.html` — қызметтер каталогы, іздеу және сүзгі.
- `booking.html` — автосервиске жазылу формасы.
- `login.html` — кіру интерфейсі.
- `register.html` — тіркелу интерфейсі.

## Жобаны ашу
1. ZIP архивін шығарыңыз.
2. Қалтаны `C:\xampp\htdocs\` ішіне көшіріңіз.
3. XAMPP Control Panel ішінен **Apache** іске қосыңыз. Қазір статикалық беттер үшін MySQL міндетті емес.
4. Браузерде `http://localhost/autoservice_management/` мекенжайын ашыңыз.

Егер қалтаның атауы өзгертілсе, URL-дегі атауды да соған сай өзгертіңіз.

## Дерекқордың бастапқы кестелері
`users`, `vehicles`, `services`, `appointments`, `service_history`. SQL үлгісі `database/schema.sql` файлында. Бұл схема кейінгі PHP/MySQL кезеңдеріне арналған.

## Келесі кезеңдегі жоспар
- PHP арқылы формаларды серверде өңдеу.
- MySQL-ге PDO арқылы қосылу.
- Тіркелу/кіру, сессия және рөлдерді енгізу.
- Жазылуларды қосу, көру, өңдеу және жою (CRUD).
- Сервер жағындағы іздеу/сүзгі және қауіпсіздік тексерістері.
