# AutoCare — Автосервис қызметтерін басқару жүйесі

## 1. Жоба туралы
**Жоба атауы:** AutoCare  
**Тақырыбы:** Автосервис қызметтерін басқару жүйесі.

**Мақсаты:** Клиенттерге автосервис қызметтерін қарауға, көліктері туралы мәлімет енгізуге және техникалық қызмет көрсетуге жазылуға мүмкіндік беретін веб-қосымша әзірлеу.

## 2. Қолданылатын технологиялар
- HTML5, CSS3, JavaScript
- PHP, MySQL, PDO
- Git және GitHub
- XAMPP

## 3. Негізгі мүмкіндіктер
- Басты бетті және қызметтер каталогын көрсету.
- Қызметтерді іздеу және санат бойынша сүзу.
- Пайдаланушыны тіркеу және жүйеге кіргізу.
- Құпиясөзді `password_hash()` арқылы хэштеу және `password_verify()` арқылы тексеру.
- PHP сессиясын басқару және жүйеден шығу.
- Жүйеге кірген пайдаланушыға ғана жазылу бетін ашу.
- Жазылу формасын `$_POST` арқылы өңдеу және серверде тексеру.
- Қызметтерді `$_GET` арқылы іздеу/сүзу.
- Ортақ `header.php` және `footer.php` бөліктерін `include/require` арқылы қосу.

## 4. Негізгі беттер
| Файл | Қызметі |

## 6. Дерекқор
Дерекқор атауы: `autocare_db`.

Кестелер:
- `users` — пайдаланушылар;
- `vehicles` — пайдаланушылардың көліктері;
- `services` — автосервис қызметтері;
- `appointments` — жазылулар;
- `service_history` — қызмет көрсету тарихы.

Схема: `database/schema.sql`.  
ER-диаграмма: `docs/ER-diagram.svg`.

## 7. Апталар бойынша орындалған жұмыстар
### 8-апта — Жоспарлау
Тақырып, мақсат, функциялар, беттер тізімі, дерекқор моделі, ER-диаграмма және GitHub репозиторийі дайындалды.

### 9-апта — Frontend
HTML беттері, CSS адаптивті интерфейсі, JavaScript функциялары, іздеу/сүзу және браузерлік форма тексерістері әзірленді.

### 10-апта — PHP негіздері
HTML беттерінің PHP нұсқалары жасалды. Ортақ header/footer бөліктері бөлінді. `$_GET` арқылы қызметтерді іздеу/сүзу, `$_POST` арқылы жазылу формасын өңдеу және серверлік тексеру енгізілді. Жазылу деректері `vehicles` және `appointments` кестелеріне сақталады.

### 11-апта — Дерекқор және аутентификация
PDO арқылы MySQL-ге қосылу қолданылады. Тіркелу кезінде құпиясөз `password_hash()` арқылы сақталады. Кіру кезінде `password_verify()` қолданылады. `session_start()` және `session_regenerate_id(true)` арқылы сессия басқарылады. `logout.php` жүйеден шығарады. `includes/auth.php` жүйеге кірмеген пайдаланушыны қорғалған беттен `login.php` бетіне бағыттайды.

## 8. Жергілікті ортада іске қосу
1. XAMPP-та Apache және MySQL қызметтерін іске қосыңыз.
2. Жоба папкасын `C:\xampp\htdocs\` ішіне орналастырыңыз.
3. phpMyAdmin ашып, `database/schema.sql` файлын импорттаңыз.
4. `config/database.php` ішіндегі дерекқор атауы, қолданушы аты және парольді жергілікті XAMPP баптауына сәйкестендіріңіз.
5. Браузерден жоба папкасының нақты атымен ашыңыз. Мысалы, папка `autoservice_management` болса: `http://localhost/autoservice_management/`.

## 9. Апталық есептер
Әр аптаның есебі `weekly-reports/` қалтасында сақталады. Тексеру чек-парағындағы тармақтарды тек нақты тесттен кейін ғана орындалды деп белгілеу керек.
