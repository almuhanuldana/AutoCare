
# AutoCare — Автосервис қызметтерін басқару жүйесі

## 1. Жоба туралы

**Жоба атауы:** AutoCare  
**Тақырыбы:** Автосервис қызметтерін басқару жүйесі.

**Мақсаты:** Клиенттерге автосервис қызметтерін қарауға, көліктері туралы мәлімет енгізуге және техникалық қызмет көрсетуге жазылуға мүмкіндік беретін веб-қосымша әзірлеу.

## 2. Қолданылатын технологиялар

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- PDO
- Git және GitHub
- XAMPP

## 3. Жобаның негізгі мүмкіндіктері

1. Басты бетті көрсету.
2. Автосервис қызметтерінің каталогын қарау.
3. Қызметтерді іздеу және санат бойынша сүзу.
4. Қызметке жазылу формасын толтыру.
5. Пайдаланушыны тіркеу интерфейсі.
6. Жүйеге кіру интерфейсі.
7. PHP арқылы формаларды серверде өңдеу.
8. GET және POST әдістерін пайдалану.
9. Сервер жағында енгізілген мәліметтерді тексеру.
10. Ортақ Header және Footer бөліктерін пайдалану.

## 6. Дерекқор құрылымы

Жобаның дерекқор моделі бес кестеден тұрады:

- users — пайдаланушылар.
- vehicles — көліктер.
- services — автосервис қызметтері.
- appointments — жазылулар.
- service_history — қызмет көрсету тарихы.

Дерекқор схемасы `database/schema.sql` файлында орналасқан.

ER-диаграмма: `docs/ER-diagram.svg`.

## 7. 8–10 апталар бойынша орындалған жұмыстар

### 8-апта: Жоспарлау

- Жоба тақырыбы таңдалды.
- Жобаның мақсаты мен функциялары анықталды.
- Негізгі беттердің тізімі жасалды.
- Дерекқор құрылымы жоспарланды.
- ER-диаграмма әзірленді.
- GitHub репозиторийі құрылды.

### 9-апта: Frontend

- HTML беттері әзірленді.
- CSS арқылы интерфейс безендірілді.
- Адаптивті дизайн жасалды.
- JavaScript функциялары қосылды.
- Қызметтерді іздеу және сүзу іске асырылды.
- Формаларға браузерлік валидация қосылды.

### 10-апта: PHP негіздері

- HTML беттері PHP файлдарына көшірілді.
- Header және Footer жеке файлдарға бөлінді.
- PHP жобасының қалта құрылымы ұйымдастырылды.
- Формаларды өңдеуде `$_POST` және `$_GET` қолданылды.
- Серверлік валидация енгізілді.

## 8. Жобаны іске қосу

1. XAMPP бағдарламасын орнату.
2. AutoCare папкасын `htdocs` ішіне орналастыру.
3. Apache және MySQL қызметтерін іске қосу.
4. MySQL дерекқорын `database/schema.sql` арқылы импорттау.
5. `config/database.php` файлындағы қосылу параметрлерін тексеру.
6. Браузерден ашу:

`http://localhost/AutoCare/`

Ескерту: дерекқорға тәуелді беттерді ашу үшін MySQL қосулы және дерекқор құрылған болуы керек.
