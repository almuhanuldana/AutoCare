
# AutoCare — Автосервис қызметтерін басқару жүйесі

## 1. Жоба туралы

**Жоба атауы:** AutoCare  
**Тақырыбы:** Автосервис қызметтерін басқару жүйесі.

**Мақсаты:** Клиенттерге автосервис қызметтерін қарауға, көліктері туралы мәлімет енгізуге және техникалық қызмет көрсетуге жазылуға мүмкіндік беретін веб-қосымша әзірлеу.

## 2. Қолданылатын технологиялар

- HTML5, CSS3, JavaScript
- PHP
- MySQL
- PDO
- Git және GitHub
- XAMPP

## 3. Негізгі мүмкіндіктер

- Басты бет және автосервис қызметтерінің каталогы.
- Қызметтерді іздеу және санат бойынша сүзу.
- Пайдаланушыны тіркеу және жүйеге кіргізу.
- Құпиясөзді `password_hash()` арқылы хэштеу және `password_verify()` арқылы тексеру.
- PHP сессияларын басқару және жүйеден шығу.
- Жүйеге кірген пайдаланушыға ғана жазылу мүмкіндігін беру.
- Жазылу формасын `$_POST` арқылы өңдеу және сервер жағында тексеру.
- Жазылуларды көру, қосу, өңдеу және өшіру (CRUD).
- Жазылуларды қызмет түрі және күні бойынша сүзу.
- Жазылуларды іздеу және сұрыптау.
- Жазылулар тізімін беттерге бөлу (pagination).
- CSRF токенін тексеру.
- PDO және дайындалған SQL сұраныстарын пайдалану.
- Ортақ `header.php` және `footer.php` бөліктерін қосу.

## 6. Дерекқор

**Дерекқор атауы:** `autocare_db`

Жобада келесі кестелер қолданылады:

- `users` — пайдаланушылар туралы ақпарат;
- `vehicles` — пайдаланушылардың көліктері;
- `services` — автосервис қызметтері;
- `appointments` — қызметке жазылулар;
- `service_history` — қызмет көрсету тарихы.

Дерекқор схемасы: `database/schema.sql`  
ER-диаграмма: `docs/ER-diagram.svg`

## 7. Апталар бойынша орындалған жұмыстар

### 8-апта — Жоспарлау

Жобаның тақырыбы, мақсаты, негізгі функциялары анықталды. Беттер тізімі, дерекқор моделі және ER-диаграмма дайындалды. GitHub репозиторийі құрылды.

### 9-апта — Frontend әзірлеу

HTML беттері жасалды. CSS арқылы интерфейс безендірілді және адаптивті дизайн қосылды. JavaScript көмегімен іздеу, сүзу және форма тексерістері орындалды.

### 10-апта — PHP негіздері

HTML беттерінің PHP нұсқалары жасалды. Ортақ header және footer бөліктері бөлінді. `$_GET` арқылы іздеу және сүзу, `$_POST` арқылы формаларды өңдеу енгізілді. Жазылу деректері MySQL дерекқорына сақталатын болды.

### 11-апта — Дерекқор және аутентификация

PDO арқылы MySQL дерекқорына қосылу жүзеге асырылды. Пайдаланушыны тіркеу, жүйеге кіру және жүйеден шығу функциялары қосылды. Құпиясөздер хэштеліп сақталады. Сессия арқылы пайдаланушының авторизациясы тексеріледі.

### 12-апта — CRUD операциялары

Жазылуларды қосу, көру, өңдеу және өшіру функциялары әзірленді. Пайдаланушы тек өз жазылуларын басқара алады. Мәліметтерді жаңарту кезінде дерекқор транзакциялары қолданылады.

### 13-апта — Іздеу, сүзу және сұрыптау

Жазылулар тізіміне іздеу және сүзу мүмкіндіктері қосылды. Жазылуларды күні, қызмет түрі және мәртебесі бойынша сұрыптау қарастырылды. Pagination арқылы жазылулар бірнеше бетке бөлінеді. Формаларда деректерді тексеру және CSRF қорғанысы қолданылады.

## 8. Жергілікті ортада іске қосу

1. XAMPP бағдарламасын ашыңыз.
2. Apache және MySQL қызметтерін іске қосыңыз.
3. AutoCare жобасын `C:\xampp\htdocs\` папкасына орналастырыңыз.
4. Браузерден `http://localhost/phpmyadmin/` адресін ашыңыз.
5. `database/schema.sql` файлын импорттаңыз.
6. `config/database.php` файлындағы дерекқор баптауларын тексеріңіз.
7. Браузерден жобаны ашыңыз. Мысалы:

```text
http://localhost/AutoCare/
```

Егер жоба папкасының атауы басқа болса, URL мекенжайында сол атауды қолданыңыз.
